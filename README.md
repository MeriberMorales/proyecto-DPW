
Cafetería Aroma Café

Sitio web desarrollado con **HTML5, CSS3 y JavaScript** para promocionar la cafetería **Aroma Café**, ofreciendo información sobre el negocio, su menú, galería de productos y datos de contacto.
El sitio incluye:

- Página de inicio
- Menú de bebidas
- Información sobre la cafetería
- Galería de productos
- Información de contacto
- Integración con redes sociales
- Optimización SEO
- Metadatos Open Graph y Twitter Cards
